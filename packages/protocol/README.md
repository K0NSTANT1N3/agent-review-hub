# @quorum/protocol

Shared schemas for [Quorum](https://github.com/K0NSTANT1N3/agent-review-hub): the Leader and Node wire protocol, config parsing (`parseLeaderConfig`, `parseNodeConfig`) and join codes (`@quorum/protocol/join-code`).

You do not install this package yourself. `@quorum/leader`, `@quorum/node` and `@quorum/cli` depend on it.
